- 编译主/测试 APK、42 项 JVM 测试和 lint 通过；5 项同步引擎设备测试通过。
- 故障注入：先保存完整远程文件及本地/远程成功凭据，再把音频、TXT、JSON、摘要、metadata 和 Markdown 全部替换为较短文件，关闭 Store 并新建 WebDAV 客户端/引擎。重试整份覆盖所有短文件，完成后重复同步零音频/转写重传。电脑端额外核对音频 SHA-256、全文、摘要、metadata 和 Markdown 内容摘要。
